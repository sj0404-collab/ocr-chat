# Дообучение CRNN под шрифты (цепочка r4 → r13)

Пайплайн дообучения кириллической CRNN (111 классов, CTC, blank=109, unk=110,
вход 1×1×32×W) под конкретные шрифты. Именно так получены модели r5…r13
в релизе v1.0.0.

## Файлы

- `crnn_torch.py` — архитектура модели на PyTorch (5 conv + 2 двунаправленных GRU + Linear→111)
  и загрузка весов из оригинального ONNX (`load_onnx_weights`) с маппингом гейтов
  GRU из ONNX-порядка (z,r,n) в torch-порядок (r,z,n).
- `finetune_chain.py` — основной скрипт одной стадии дообучения.
- `finetune.py` (исторический, в ocr_test2) — первый дообуч r4 (обратите внимание:
  `crnn_chain`-вариант грузит `.onnx` со стилем имен torch-export, оригинальная
  Yomikai-модель — через `load_onnx_weights`).

## Данные

Полностью **синтетика**: строки генерируются из словаря слов + набора фраз
(кириллица RU/UK, знаки, цифры), рисуются PIL-ом с аугментациями
(размер 12–42pt, блюр, микронаклон ±1.2°, случайные тона чернил/фона),
затем строка масштабируется до высоты 32px и кладётся **слева на белый холст**
с правым паддингом до кратности 8 (иногда +случайный пад) — как в `readLine`
Android-движка. Вход нормализуется как `luma/255` (белое=1.0).

## Loss/оптимизация

- CTC loss (blank=109, `zero_infinity=True`); длины входа масштабируются по
  доле контента в холсте (T * content_w / maxw).
- AdamW lr=5e-5, weight_decay=1e-5, grad clip 5.0, batch 16, ~900 шагов
  (~7–8 мин на 2 CPU-ядрах, torch threads=2).

## Дообучение цепочкой

Одна стадия = один шрифт. Следующая стадия стартует не с оригинала, а с
**предыдущей модели** — знания копятся (`r4 → r5(gothic) → … → r13`).

**Анти-забывание**: микс батчей: 45% целевой шрифт + ~9–12% каждый из уже
выученных рукописных + 10% печатный DejaVu (контроль печатной базы).
Оценка **CER до/после** по целевому шрифту, по DejaVu и по миксу — печатную
базу цепочка не рвёт (DejaVu CER держится 0.002–0.007).

## Как запускать

```bash
python3 finetune_chain.py \
  --inp models/best_r8_pacifico.onnx \
  --out models/best_r9_caveat.onnx \
  --font fonts/Caveat.ttf --p 0.45 \
  --prev fonts/MarckScript.ttf fonts/BadScript.ttf fonts/Pacifico.ttf \
  --steps 900 --tag r9_caveat
```

Финальная «все в одну» — целевым шрифтом любой рукописный с p=0.16,
остальные 6 рукописных в `--prev` (равномерно) + DejaVu 0.1, шагов 1200.

## Экспорт

`torch.onnx.export` (opset 14, legacy-экспортер), динамическая ось ширины,
вход `x`, выход `logit` — ровно тот формат, который едят и `onnxruntime-android`
в APK, и onnxruntime-web в браузерной версии. Веса всех экспортов цепочки
имеют torch-имена (`conv.N.weight`…, `onnx::GRU_*`, `onnx::MatMul_*`) —
загрузчик в finetune_chain.py определяет порядок гейтов автоматически
(сравнение выхода torch vs onnxruntime на случайном входе).

## Требования

Python 3.11+, пакеты: `torch` (CPU-сборки достаточно), `onnx`, `onnxruntime`,
`pillow`. Шрифты — любые TTF с кириллическими глифами (использовались:
Marck Script, Bad Script, Pacifico, Caveat, Neucha, Underdog, Kelly Slab +
DejaVu как контрольная база, google/fonts, OFL).
